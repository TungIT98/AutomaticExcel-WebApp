===============================================
    HƯỚNG DẪN SỬ DỤNG EXCEL-TO-WORD CONVERTER
===============================================

📋 MÔ TẢ:
Chương trình chuyển đổi dữ liệu từ file Excel sang các file Word template.

🔧 CÁCH SỬ DỤNG:
1. Chuẩn bị file Excel với cấu trúc dữ liệu phù hợp
2. Đặt file Excel vào thư mục gốc (cùng cấp với file .exe)
3. Đổi tên file Excel thành "0. Hoso.xlsx"
4. Chạy file "ExcelToWordConverter.exe"
5. Kết quả sẽ được tạo trong thư mục "output/"

📁 CẤU TRÚC THƯ MỤC:
- ExcelToWordConverter.exe (chương trình chính)
- 0. Hoso.xlsx (file Excel dữ liệu)
- templates/ (thư mục chứa template Word)
- output/ (thư mục kết quả)

⚠️ LƯU Ý:
- File Excel phải có đúng cấu trúc dữ liệu
- Đảm bảo thư mục templates có đầy đủ file Word
- Không được xóa hoặc di chuyển các file template

🆘 HỖ TRỢ:
Nếu gặp lỗi, vui lòng liên hệ admin để được hỗ trợ.
